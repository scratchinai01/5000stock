# 5000 萬股市大富翁實戰模擬系統 v2（前台 + 後台）

給課堂使用的模擬交易競賽系統。學生以 5,000 萬（可調整）起始資金交易台股、ETF、債券 ETF、台指期、台指選擇權、美股、國際原物料期貨與加密貨幣；老師／助教在後台管理帳號、稽核每一筆成交的報價來源與時間。

這一版是完全重寫，核心原則只有一條：**價格只能來自真實資料，而且一定要知道是哪個時間點的價格。**

---

## 和舊版最大的差異

| 項目 | 舊版 | 新版 |
|---|---|---|
| 成交價從哪來 | 前端把價格送給後端，可被竄改；查不到時用程式內建數字補位 | **伺服器決定成交價**，前端只能送「代號、方向、數量」；查不到真實報價就不能交易 |
| 報價時間 | 舊收盤價被蓋上「現在時間」、Yahoo 資料一律標成固定日期 | 每個價格都附「報價日期、時間、時區、來源、等級」，寫進每一筆成交 |
| 時區 | 依伺服器/瀏覽器時區判斷星期，UTC 主機會判錯夜盤 | 全部以 Asia/Taipei（美股用紐約、原物料用芝加哥）計算，自動處理夏令時間 |
| 帳務 | 前端計算，存在 Firestore（規則全開） | 伺服器端計算並寫入 SQLite（交易內完成、不會超買），NAV 可對帳 |
| 密碼 | 前端雜湊 | 伺服器端 scrypt + httpOnly session cookie |
| 後台 | 管理面板功能分散 | 帳號、成交稽核、報價管理、商品設定、系統設定、操作紀錄、資料庫備份 |

## 報價來源等級

| 等級 | 意義 | 來源 |
|---|---|---|
| 即時 LIVE | 交易所即時資料 | FinMind 盤中快照（需 Token）、Binance |
| 盤中延遲 DELAYED | 盤中、但有延遲 | Yahoo Finance（交易時段內、60 分鐘內的報價） |
| 收盤價 CLOSE | 最近一個交易日的收盤／結算價 | FinMind 日資料、Yahoo |
| 管理員手動報價 MANUAL | 老師輸入，必須註明來源 | 後台「報價管理」 |

- 報價日期早於今天（台北）時標示「非今日」。系統設定可選擇是否允許以舊報價成交。
- 供應商暫時失敗時，會依序改用：管理員手動報價 → 最後一次成功取得的真實報價（保留原本日期，一看就知道是舊的）→ 拒絕交易。
- **系統中沒有任何寫死的價格。** 商品目錄只有合約規格（乘數、單位、保證金比例）。

## 功能

**學生端**
- 資產總覽：NAV、現金、已實現／未實現損益，每個部位的現價都標示報價依據
- 下單：搜尋全台股 4,300+ 檔與各類商品；伺服器試算成交價、手續費、交易稅、保證金；送出前顯示成交價屬於哪個時間點
- 支援現股多空（融券）、期貨多空、選擇權買方、美股（自動以匯率換算台幣）、加密貨幣；可部分平倉
- 交易紀錄：同時顯示「下單時間」與「成交價所屬的報價時間」
- 全班排行榜、市場時鐘

**後台（管理員）**
- 總覽：以非今日報價／手動報價／非交易時段成交的筆數、匯率狀態、報價連線狀態
- 學生帳號：新增、批次建立（從 Excel 貼上）、停用、重設密碼、重置資金、刪除、查看個人帳戶
- 成交稽核：依報價等級、非今日、非交易時段、商品、日期篩選；標記可疑成交；匯出 CSV（含報價來源欄位）
- 報價管理：逐類檢查每個商品是否取得報價；設定手動報價（備援／覆蓋）；設定 FinMind Token；清除快取
- 商品設定：啟用／停用、保證金比例、新增自訂商品（Yahoo 代號即可）
- 系統設定：起始資金、自行註冊、僅限交易時段、是否允許舊報價、盤中報價最長延遲、手動匯率、暫停交易
- 操作紀錄、資料庫備份下載

## 執行

需要 **Node.js 22.13 以上**（使用內建 `node:sqlite`，不需安裝資料庫）。

```bash
npm install
cp .env.example .env        # 依需要修改
npm run dev                 # 開發模式 http://localhost:3000
```

首次啟動會建立管理員帳號。若沒設定 `ADMIN_PASSWORD`，隨機密碼會印在主控台，登入後請立即修改。

正式環境：

```bash
npm run build
npm start
```

其他指令：`npm test`（交易引擎與交易時鐘單元測試）、`npm run typecheck`。

### 部署注意事項

- 資料存在 `DATA_DIR`（預設 `./var/tycoon.db`）。**Cloud Run、AI Studio 這類無狀態平台重啟會清空本機檔案**，請掛載永久磁碟到 `DATA_DIR`，或定期從後台下載備份。
- 提供 `Dockerfile`（資料目錄 `/data`，內含 Litestream 雲端備份，見下方 Google Cloud Run 說明）。
- 課堂區網用 `http://IP` 直接連線的正式模式，請設 `INSECURE_COOKIE=1`，否則瀏覽器不會儲存登入 cookie。
- 報價需要能連到 `api.finmindtrade.com`、`query1.finance.yahoo.com`、`api.binance.com`。Yahoo 為非官方介面，可能偶爾失效，此時會自動改用備援並在後台顯示。

## 部署到 Render（推送 GitHub 自動部署）

專案根目錄的 `render.yaml` 已設定好服務、硬碟與環境變數。

1. 到 https://dashboard.render.com 用 GitHub 登入。
2. 點「New」→「Blueprint」，選 `5000stock` repo。
3. 畫面會列出要建立的服務 `5000stock`，在 `ADMIN_PASSWORD` 欄位輸入管理員密碼（`FINMIND_TOKEN` 可留空），按「Apply」。
4. 等待建置完成（第一次約 5–10 分鐘），Render 會給一個 `https://5000stock-xxxx.onrender.com` 網址。
5. 之後每次推送到 `main` 都會自動重新部署，資料存在硬碟 `/data`，不會因部署而消失。

注意：永久硬碟只有付費方案（Starter 以上）提供；改用免費方案資料會在重啟或休眠後消失，只適合試用。費用以 Render 公告為準。

## 部署到 Google Cloud Run（推送 GitHub 自動部署）

Cloud Run 每次重啟都會清空容器硬碟，所以本專案用 **Litestream** 把 SQLite 每秒備份到 Cloud Storage，容器啟動時自動還原（`deploy/start.sh`、`deploy/litestream.yml`，已包含在 `Dockerfile`）。

1. **建立 Cloud Storage bucket**：區域建議 `asia-east1`（台灣），其餘預設即可。
2. **建立 Cloud Run 服務**：選「從存放區持續部署 (GitHub)」，透過 Cloud Build 連接 `5000stock`，分支 `main`，建置類型選 **Dockerfile**。
3. **服務設定**：
   - 區域 `asia-east1`；驗證選「允許未經驗證的叫用」（學生要能開網頁）
   - 容器連接埠 `8080`
   - **執行個體數量上限 = 1**（SQLite 只能有一個寫入者，必設）；下限可設 0
   - CPU 建議選「一律分配」（以執行個體計費），讓備份在沒有請求時也能進行
   - 環境變數：
     - `LITESTREAM_REPLICA_URL` = `gcs://你的bucket名稱/tycoon.db`
     - `ADMIN_PASSWORD` = 管理員初始密碼
     - `FINMIND_TOKEN` = （選填）
4. **授權備份**：到 bucket 的「權限」，把 Cloud Run 使用的服務帳戶加入，角色選「Storage 物件管理員 (Storage Object Admin)」。
5. 部署完成後 Cloud Run 會給一個 `https://…run.app` 網址。之後每次推送到 `main` 都會自動重新部署，資料會保留。

注意：部署切換的短暫期間可能同時有新舊兩個容器，極少數情況下該瞬間的寫入可能遺失；正式比賽前後建議從後台下載一次資料庫備份。

## 交易規則（可在 `server/trading/fees.ts` 調整）

- 台股／ETF：手續費 0.1425%（最低 20 元）；賣出證交稅 股票 0.3%、ETF 0.1%、債券 ETF 0
- 台指期：手續費 TX 50／MTX 25／TMF 12 元每口；期交稅十萬分之二
- 台指選擇權：僅開放買方；手續費 25 元每口；交易稅為權利金的千分之一
- 美股：0.1%（最低 1 美元）；原物料：每口 2.5 美元；加密貨幣：0.1%
- 保證金：期貨與原物料預設 10%、融券 90%，可在後台逐一調整

## 專案結構

```
server/
  index.ts            進入點 (API + Vite/靜態檔)
  db.ts               SQLite schema 與交易包裝
  time.ts, clock.ts   時區工具、各市場交易時段
  instruments.ts      商品目錄 (只有規格，沒有價格)
  quotes/             報價供應商 (FinMind/Yahoo/Binance) 與報價服務
  trading/            撮合引擎、估值、手續費與稅
  auth.ts             密碼、session、權限
  routes/             學生 API (public.ts)、後台 API (admin.ts)
shared/types.ts       前後端共用型別
web/src/              React 前端 (學生頁 + 後台頁)
tests/                單元測試
data/                 台股與美股代號目錄
```
